2026-07 · proton patch hygiene
Keeping the LinUwUx hooks in a single regenerated .c file makes rebasing onto new Proton-GE / CachyOS releases far less painful. Script now handles the ntdll + signal path injection automatically.
2026-05 · native vs proton trade-offs
Hearthstone native path works, but the missing proprietary Blizzard libs still kill the in-game shop. For most titles Proton remains the pragmatic choice; native only when the engine already has a clean Linux story.
